# End-to-End (E2E) Tests

## Scope (Blueprint §35)

E2E tests will validate complete end-to-end user workflows:
1. Import Asset → Create Root Version
2. Commit Working State → Append Version
3. Branch (Continue From) → Form DAG branch
4. Fork Project → Cross-project reference without copying assets
5. Merge Versions → Operation-set composition over LCA
6. Creative Memory → Add and cite interpretative memory
7. Grounded Copilot → Ask questions with verifiable citations

Will be executed with Playwright in future implementation phases.
