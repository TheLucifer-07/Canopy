## Observability & Daily Budget Controls

- **Request Logging:** Every AI model call logs request metadata to `ai_requests` table (`purpose`, `provider`, `model`, `input_tokens`, `output_tokens`, `cost`, `latency_ms`, `status`).
- **Budget Enforcement:** Before making provider calls, `assertBudgetAvailable` checks daily accumulated token/cost usage via `getAiUsageForToday`.
- **Budget Exceeded Behavior:** Throws `429 AI_BUDGET_EXCEEDED`. Semantic Diff degrades gracefully to `declared_only` without throwing server errors.
